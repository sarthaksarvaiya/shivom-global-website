# SHIVOM GLOBAL — DESIGN & DEVELOPMENT RULES

1. **Architecture & Stack**: Preserve the existing React, Vite, TypeScript and Vanilla CSS architecture.
2. **Backend & Integrations**: Never replace or remove existing backend functionality, Supabase integration, Resend notifications, buyer enquiry APIs or dashboard functionality without explicit approval.
3. **HTML & Accessibility**: Use semantic HTML5 and accessible components.
4. **Spacing Grid**: Maintain an 8px spacing grid.
5. **Design Tokens**: Use CSS variables for all design tokens.
6. **Motion Preferences**: Respect `prefers-reduced-motion`.
7. **Responsiveness**: Prioritize mobile-first responsive design.
8. **Imagery**: Use premium, authentic Indian tea photography.
9. **Visual Direction**: Use Deep Forest, Forest Dark, Warm Cream and Warm Gold as the visual direction.
10. **Animations**: Animations must be smooth, lightweight and performance-conscious.
11. **Design Aesthetics**: Avoid excessive gradients, glowing effects, unnecessary cards and generic AI-generated website layouts.
12. **Content & Integrity**: Never invent business claims, certifications, sourcing facilities, stock availability or customer testimonials.
13. **Positioning**: Preserve existing business positioning and approved website architecture.
14. **Performance & SEO**: Optimize SEO, accessibility, loading performance and Core Web Vitals.
15. **Execution Workflow**: Make one approved change at a time. Audit before implementation.
16. **Browser QA Protocol**: Adhere to `docs/QA_RULES.md` using Chrome DevTools MCP. Test all form modes, preselection, required field validation, invalid inputs, error states, and responsive layouts. Never submit real buyer enquiries without explicit authorization. Return structured reports with PASS, FAIL, NOT TESTED and screenshot evidence.
